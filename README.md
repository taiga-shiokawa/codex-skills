# Codex Skills

このリポジトリは、ローカルの Codex 環境で利用しているカスタムスキルのバックアップです。

`SKILL.md` を含む各ディレクトリが1つのスキルです。Codex に追加する場合は、必要なスキルのディレクトリを `~/.codex/skills/` に配置してください。

## 含まれるもの

- 開発支援、Google Apps Script、Python / FastAPI の雛形作成
- ドキュメント作成・レビュー、日報、Obsidian への記録
- ブラウザ自動化、PDF 操作、日本語文章の推敲

## 注意

一部のスキルには、この環境固有のローカルパスや運用手順が含まれています。別の環境で使用する際は、必要に応じて内容を調整してください。

Codex に同梱される `.system` スキルは含めていません。
